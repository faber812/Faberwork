# Визуальный стиль FABER (базовый)

Основа — стиль роликов `faber_polaki_v1` и `faber_day1_v1`: тёмно-синий фон, жёлтые акценты, нумерованные пункты, простые плоские SVG-объекты. Цвета сняты с кадров этих роликов.

Всё ниже уже зашито в `styles/faber.css`. В сценах используйте классы оттуда, а не новые цвета.

## Палитра

| Токен | Цвет | Где |
|---|---|---|
| `--bg-0` | `#05080F` | края фона (виньетка) |
| `--bg-1` | `#101626` | центр фона |
| `--panel` | `#1C2438` | плашки, телефоны, карточки |
| `--slate` | `#3D4E78` | второстепенные фигуры («поляк», фон-объекты) |
| `--line` | `#4A5878` | рамки |
| `--accent` | `#FFCA2F` | номер пункта, выделенные слова, «ты» |
| `--text` | `#FFFFFF` | основной текст |
| `--muted` | `#8C97B3` | служебные надписи |
| `--bad` | `#FF4545` | штрафы, «увольнение», минус деньги |
| `--good` | `#2ED47A` | «можно», доказательство, плюс |

## Шрифты (лежат в `assets/fonts`, лицензии рядом)

- Заголовки и субтитры: Inter ExtraBold 800.
- Служебная строка вверху и цифры интерфейсов: DejaVu Sans Mono.

## Композиция кадра 1080 × 1920

- Служебная строка (`.tagline`): слева сверху, y ≈ 150. Формат `ТЕМА · ПОДТЕМА · ЧАСТЬ N`.
- Номер пункта (`.badge`): по центру, y ≈ 250.
- Иллюстрация: центр, y ≈ 450–1150.
- Субтитры (`.sub`): по центру, верх блока y ≈ 1250, максимум 2 строки, 64 px. Выделение слова — `<b>`.

## Безопасные зоны TikTok (приблизительно, проверяются автоматически)

- низ: 420 px — подпись, ник, музыка;
- право: 140 px от y = 600 и ниже — лайки, комменты, репосты;
- верх: 120 px — вкладки «Подписки / Рекомендации».

Текст в этих зонах = ошибка рендера. Если элемент намеренно заходит туда (фон, декор без текста), ставьте ему `data-safe-ignore`.

## Звук

- Итоговая громкость −14 LUFS, true peak ≤ −1.5 dBTP (делает рендер).
- Музыка под голосом — на 18–22 dB тише речи.

## Персонаж Макс

Пока не утверждён: эталона нет, в опубликованных роликах персонажа нет. Не рисовать Макса, пока не будет утверждённого референса в `assets/max/`.
